# 四旋翼控制實驗台 Quadcopter Control Lab

[English](README.md) | **繁體中文**

**▶ 線上使用：https://adevlog.github.io/drone-sim/**

在瀏覽器裡看懂 PID 和感測器怎麼影響飛行：命令 → 串級 PID → mixer → 馬達 → 機體 → 感測器 → 回授，每個訊號都看得到、每個參數都調得到，調完立刻看到飛機怎麼反應。單一 HTML 檔，不需要安裝。

## 可以做什麼

| 模式 | 內容 |
|---|---|
| 單軸測試架（Roll / Pitch / Yaw / 油門） | 其他軸鎖住，只看一個通道的串級 PID；方波、步階、正弦命令；上升時間、過衝、穩定時間、穩態誤差 |
| 三軸姿態 | 三軸同時控制、軸間耦合、高度保持與傾斜補償；PFD 主飛行顯示器 |
| 自由飛行 | PX4 飛行模式 Acro / Stabilized / Altitude / Position；遙控解鎖、墜機判定、軌跡 |
| 考照練習 | 依 AC107-005D 圖 9 的專業基本級多旋翼場地；飛手視角、懸停 5 秒計時、容許帶與高度提示 |
| 懸停調參 | 從 2 m 空中懸停開始、鏡頭鎖定飛機；原點十字、目標點與偏移線；懸停指標（偏移、傾斜、角速度抖動、PWM 抖動） |

- 點方塊圖任一格，會跳出該環節的公式，並代入目前的即時數值。
- 參數使用 PX4 名稱（`MC_ROLLRATE_P`、`MPC_XY_VEL_P_ACC`…），可切換「PX4 預設」與「消費級」兩種操控手感。
- **馬達與感測器面板**（三軸姿態、自由飛行、懸停調參）：四顆馬達效率（PX4 編號）、陀螺儀雜訊 / 零點偏差 / 濾波、加速度計雜訊 / 零點偏差；姿態估測可選用陀螺儀、加速度計或兩者（簡化版 Kalman），並畫出真實與估測角度。
- 可以試：把一顆馬達調弱再把 RATE_I 調成 0 → 停在固定偏角、越飄越遠；P 調小 → 明顯晃動；有陀螺儀雜訊時 D 調大 → 馬達輸出抖動；只用陀螺儀估測 + 零點偏差 → 積分漂移。

## 手勢飛行（實驗）

**▶ https://adevlog.github.io/drone-sim/gesture/**

用手飛：AI 手部辨識模型（MediaPipe，在瀏覽器本地執行）透過 webcam 追蹤指尖，你撥動一顆虛擬球，球的轉動就是飛機的命令（定高、Position 模式）。需要相機與 https（線上版可用）。做法與設計理由見 [gesture/REPORT.zh-TW.md](gesture/REPORT.zh-TW.md)。

## 操作（美國手 / Mode 2）

| 動作 | 鍵盤 | Xbox 手把 / 畫面搖桿 |
|---|---|---|
| 油門 | W / S | 左搖桿上下 |
| 偏航 Yaw | A / D | 左搖桿左右 |
| 俯仰 Pitch | ↑ / ↓ | 右搖桿上下 |
| 滾轉 Roll | ← / → | 右搖桿左右 |
| 解鎖 | 按住 S + D 約 1 秒 | 左搖桿壓到右下角約 1 秒 |
| 上鎖 | 落地後按住 S + A 約 1 秒 | 左搖桿壓到左下角約 1 秒 |
| 全螢幕 / 重飛 | F / R | 3D 視窗右上角按鈕 |

手把需要在 HTTPS 網頁或本機開啟時才能讀取（線上版可直接使用）。

## 本機執行

下載 `index.html`，用 Chrome / Edge / Firefox 開啟即可。three.js 從 cdnjs 載入，需要網路。

## 文件與測試

- [ARCHITECTURE.md](ARCHITECTURE.md)：程式結構、模組地圖、事件表、物理 / 控制器 / 感測器的設計理由、新增 / 刪除功能的步驟。
- [gesture/REPORT.zh-TW.md](gesture/REPORT.zh-TW.md)：手勢飛行技術報告（模型、座標映射、鏡像判斷、挑手、已知問題）。

## 說明

本專案為控制原理教學用途。物理參數為典型 1.5 kg 四旋翼的估計值，「消費級」手感的數值是依考照練習挑選，**不是任何特定機型的實測數據**，也不能取代實機訓練與術科考試規範。磁力計、氣壓高度計、GPS 目前假設完美。
